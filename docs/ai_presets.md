# ИИ-пресеты

Две независимые ветки работы с ИИ:

| Команда | Что делает | История |
|---|---|---|
| `/ai <вопрос>` | Свободный вопрос к модели | Да, `user_history`, TTL 1 час |
| `/idioma <текст>` | Перевод по жёсткому system-prompt | Нет, каждый запрос независим |

`/ai` живёт в `ai_handlers.py` и не меняется. `/idioma` — в `preset_handlers.py`
и не читает и не пишет `user_history`, поэтому переводы не засоряют контекст
свободного чата (и наоборот).

## Архитектура

Разделение по ответственности:

```
presets.py          → данные: Preset(name, description, system_prompt) + PRESETS
preset_handlers.py  → доставка: роутер, парсинг команды, ответ в Telegram
openai_service.py   → инфраструктура: клиент OpenRouter, выбор модели, ошибки
```

`preset_handlers.py` не знает, какая модель используется: он собирает
`messages` и вызывает `ask_openrouter()`. Смена модели или провайдера
делается только в `openai_service.py`.

## Пресет `idioma`

Логика задана промптом, без определения языка на стороне кода:

- текст на испанском → перевод на русский;
- любой другой язык (русский, украинский, английский, …) → перевод на испанский;
- возвращается только перевод, без пояснений;
- текст не сокращается и не пересказывается;
- имена, ссылки и код не переводятся.

Команда без текста отвечает подсказкой с примером.

## Как добавить новый пресет

1. Описать константу в `presets.py` и добавить её в `PRESETS`:

   ```python
   SUMMARY = Preset(
       name="summary",
       description="Краткое резюме текста",
       system_prompt="Сделай краткое резюме текста в 3–5 пунктах...",
   )

   PRESETS = {preset.name: preset for preset in (IDIOMA, SUMMARY)}
   ```

2. Добавить хендлер в `preset_handlers.py`:

   ```python
   @preset_router.message(Command("summary"))
   async def summary_handler(message: Message) -> None:
       preset = PRESETS["summary"]
       args = (message.text or "").split(maxsplit=1)
       if len(args) < 2 or not args[1].strip():
           await message.answer("Напиши текст после команды: /summary ...")
           return
       await _run_preset(message, preset, args[1].strip())
   ```

3. Добавить команду в `set_bot_commands()` в `main.py`, чтобы она появилась в меню.

Роутер подключается один раз в `main.py` — новые команды в нём регистрируются
автоматически.

## Ограничения

- **Лимит Telegram — 4096 символов.** Ответы длиннее 4000 символов режутся по
  абзацам на несколько сообщений (`_split_for_telegram`).
- **Модель — бесплатная** (`openrouter/free`). Возможны rate limit (429) и
  нестабильное качество перевода; текст ошибки возвращается пользователю.
- **Пресеты не сохраняются между запросами**: ни истории, ни состояния.
- **Пользовательских пресетов нет** — набор задаётся в коде.

## Проверка после изменений

| Сценарий | Ожидание |
|---|---|
| `/ai почему небо голубое` | ответ с учётом истории, как раньше |
| `/idioma привет, как дела` | испанский текст |
| `/idioma hola, ¿qué tal?` | русский текст |
| `/idioma hello` | испанский текст |
| `/idioma` без текста | подсказка с примером |
| `/idioma` с текстом > 4000 символов | несколько сообщений |
| `/start`, `/init_tg`, ссылка на видео | поведение не изменилось |
| `/unknown` | тишина (команда не перехватывается) |
